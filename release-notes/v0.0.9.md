model-prices 0.0.9 prices web search calls beside tokens, so a request that searched can be priced whole. Calls that pass no tool calls cost what they did.

## Changes that affect callers

- `cost()` and `Rates.breakdown()` take `tool_calls`, such as `{"web_search": 3}`, priced per 1,000 at `Rates.tools`; `CostBreakdown.tools` reports their cost, and `total` includes it. Each tool name is one billing unit, so a count means the same on every model: `web_search` a search or search tool call, `web_search_prompt` a Google grounded prompt on Gemini 2.5, `web_search_preview` an OpenAI preview search call, and `web_search_fast` a Perplexity fast search. A count for a tool the model does not price raises `ValueError`; a zero count is ignored. Modes, batch discounts, schedules, and regions do not scale tool fees ([`dee455e`](https://github.com/wakamex/model-prices/commit/dee455e6baa82658a058b671dcb9954f5a379476)).
- The fees are $10 per 1,000 at OpenAI, Anthropic, and Alibaba, $14 at Google's Gemini 3 models and $35 per grounded prompt at Gemini 2.5, $5 at xAI, and $2.50, or $1.00 fast, at Perplexity; OpenAI's preview search costs $10 on reasoning models and $25 on others. The README maps each provider's usage report to `tool_calls`, and says where a report's count differs from what is billed ([`dee455e`](https://github.com/wakamex/model-prices/commit/dee455e6baa82658a058b671dcb9954f5a379476)).

## Price data

- Tool fees come from [models.dev](https://models.dev), from corrections where it is wrong, such as Perplexity's Agent API fee, and from a new rule file, `data/tools.toml`, for fees it lacks; a model's first recorded fee also prices its earlier usage. `model-prices check` compares every fee with the providers' pages, which all match, and lists fees no page states as unchecked ([`dee455e`](https://github.com/wakamex/model-prices/commit/dee455e6baa82658a058b671dcb9954f5a379476)).
- A correction to a model's price in a service tier now keeps its long-prompt prices, which Gemini 2.5 Pro's flex and priority modes had lost, and Arcee's DeepSeek V4.1 Flash output costs $1.20 from 2026-11-01 ([`dee455e`](https://github.com/wakamex/model-prices/commit/dee455e6baa82658a058b671dcb9954f5a379476), [`fa74803`](https://github.com/wakamex/model-prices/commit/fa748030ec32955f83c387f81b05a47fd0dcd7fb)).
- `model-prices check` lists every correction in effect for a model no official page compared that day as unchecked, and the repository's `AGENTS.md` records where each kind of price comes from ([`0ca2c87`](https://github.com/wakamex/model-prices/commit/0ca2c87d452fb27ec5709872d880af6fb88d939b)).
