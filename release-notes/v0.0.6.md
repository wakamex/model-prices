model-prices 0.0.6 reads a new snapshot format, schema 2, that can gain price fields without breaking installs, and its price data takes in models.dev's changes again after models.dev moved to a new file format. Earlier releases keep working: they read schema 1, which keeps being published with the same prices.

## Changes that affect callers

- The package reads snapshots from `v2/` on the `data` branch and ignores rate fields it does not know, so later snapshots can add prices such as Alibaba's explicit cache hits or prices by modality one at a time, and this release keeps pricing everything else as before. `model-prices compile --v1 PATH` writes the schema 1 copy that releases up to 0.0.5 read from `v1/` ([`5bf98b7`](https://github.com/wakamex/model-prices/commit/5bf98b7137f38613a731d1fd6cc5407d7909ef58)).
- The history build reads models.dev's schema 2 model files, which every tracked provider has used since 2026-10-21, through the translation models.dev uses to publish them in schema 1; a file in an unknown schema stops the build instead of being skipped. This adds 96 models and 28 price changes that models.dev recorded since the move, such as GPT-6.1 Terra and Claude Mythos 5.1, and they also reach earlier releases through the published data ([`babb84e`](https://github.com/wakamex/model-prices/commit/babb84eeb71a6149aec408c59ef1d811e7ee4fb2)).
- StepFun's global models no longer take the yuan-converted prices of the China models they once linked to, such as $1.21052 instead of $1.15 output for step-3.7-flash ([`babb84e`](https://github.com/wakamex/model-prices/commit/babb84eeb71a6149aec408c59ef1d811e7ee4fb2)).
- The PyPI summary and README describe the prices as per-token prices, which price pay-per-token usage and show what a subscription's usage would cost at the same rates ([`d851334`](https://github.com/wakamex/model-prices/commit/d851334e0c1deaad6cb9c77c38d092536d7bb5af)).

## Price data

- Alibaba's pricing and context cache pages are read from the HTML their `.md` addresses now serve, and corrections give Mercury Decide's $0 and Codestral Embed's $0.015 cached input, which models.dev leaves out ([`babb84e`](https://github.com/wakamex/model-prices/commit/babb84eeb71a6149aec408c59ef1d811e7ee4fb2)).
- The website at [model-prices.com](https://model-prices.com/) links the package, code, and data from the top of its sidebar, and reports wrong prices through a GitHub issue form filled in from each page ([`6f70e27`](https://github.com/wakamex/model-prices/commit/6f70e27711ec22451c94811d8bfc9313cbecba52), [`aab5337`](https://github.com/wakamex/model-prices/commit/aab53376f5890677826a1df39f6be1b7bed48873)).
