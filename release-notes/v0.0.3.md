Price data is now published on its own, every day, so new prices reach an installed release without upgrading it. Call `model_prices.refresh()` to use the latest published data; until you do, the data bundled with the release applies, as before.

## Highlights

- `refresh(max_age=timedelta(days=1))` downloads the latest price data when the cached copy is older than `max_age`, checks its SHA-256 hash and format version, and returns a `DataStatus` with the pricing basis now in use, when that data was published, and any download error. A failed download keeps the newest cached or bundled copy and warns. `refresh(max_age=None)` never goes online. `model-prices refresh` does the same from the command line, and `model-prices rate` uses the newest copy already downloaded. Downloads are cached in `~/.cache/model-prices`, or in `MODEL_PRICES_CACHE`. ([`b5eb166`](https://github.com/wakamex/model-prices/commit/b5eb166a2ec322cd91b0b7d3f2c7bbe7398292b1))
- Every published data file stays available under its hash on the repository's [`data` branch](https://github.com/wakamex/model-prices/tree/data), so the data behind any recorded `pricing_basis()` can be fetched again. The `data@` part of the basis is now the hash of that file. ([`b5eb166`](https://github.com/wakamex/model-prices/commit/b5eb166a2ec322cd91b0b7d3f2c7bbe7398292b1))
- Each model's prices are now worked out once when the data is built, with corrections, aliases, and modes already applied, and the package only looks them up by time. A release therefore prices any later published data correctly. Prices are unchanged: the new data reproduces every lookup of 0.0.2 exactly. ([`b5eb166`](https://github.com/wakamex/model-prices/commit/b5eb166a2ec322cd91b0b7d3f2c7bbe7398292b1))
- Price changes from providers whose official pricing page agrees are published automatically each day. Changes that fail that check, or come from a provider without one (Alibaba and Moonshot AI), wait for review. ([`b5eb166`](https://github.com/wakamex/model-prices/commit/b5eb166a2ec322cd91b0b7d3f2c7bbe7398292b1))
- Prices from models.dev as of October 3, 2026, including fast-mode prices for OpenAI models and DeepSeek V4 Pro's current price. ([`a002054`](https://github.com/wakamex/model-prices/commit/a00205423cc2a8bba89c1563a778fc602642465c))

The input data files moved from the package to the repository's `data/` directory; the installed package now contains a single compiled `snapshot.json`.
