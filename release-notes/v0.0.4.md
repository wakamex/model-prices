model-prices 0.0.4 finds many more models by name, adds a thinking-mode price for Alibaba's hybrid Qwen models, and ships price data checked against far more official pricing pages. The price data itself also updates without a release: `model_prices.refresh()` keeps fetching the newest published data, which still uses schema v1, so earlier installs keep working.

## Changes that affect callers

- A model name given without a provider is now searched across every tracked lab, not only Anthropic, OpenAI, Google, Z.ai, DeepSeek, xAI, Moonshot AI, and Alibaba. Names such as `mistral-large-latest`, `MiniMax-M2.7`, `composer-2.5`, `swe-2-medium`, or `seed-2-0-pro-260328` now resolve, and matching ignores case. A name that used to return no price can now return one ([`11da8fe`](https://github.com/wakamex/model-prices/commit/11da8fe7a962aa16118b501537f929c53b301b7c), [`ad858d3`](https://github.com/wakamex/model-prices/commit/ad858d3a8dbfec8577d9315ebdb8d189be5ae75f)).
- `mode="thinking"` prices a request made with thinking on. Alibaba bills the output of its hybrid Qwen models at a separate thinking price, such as $4 against $1.2 per million output tokens for `qwen-plus`. For every other model, thinking is billed as output, so `mode="thinking"` returns the standard rates instead of `None` ([`6d08637`](https://github.com/wakamex/model-prices/commit/6d0863789fbb98b748638c601b41e910af995b33)).
- `Rates.valid_from_basis` can now be `"first observed"`: the price was read from the provider's own pricing page, and dated by the first daily run that saw it ([`a858503`](https://github.com/wakamex/model-prices/commit/a8585035c372eeed2c5fb65c9c57f1790e912ce8)).

## Price data

- Prices for models models.dev does not list are read from official pages: Cursor's Composer models, Cognition's SWE models, ByteDance's Seed models on BytePlus in US dollars, and about 80 of the providers' own models, such as Alibaba's dated Qwen snapshots and OpenAI's legacy GPT-3.5 and GPT-4 models ([`08c2335`](https://github.com/wakamex/model-prices/commit/08c2335fefa73cd60f1048829f0b65145a8352c2)).
- A daily check compares prices with the official pricing pages of 22 providers, and corrections fix the prices and dates models.dev got wrong, such as the Claude Sonnet 5.5 cache-read cut on 2026-10-07 and Alibaba's busy-hour prices for DeepSeek-V4-Flash-0731 ([`5b3662c`](https://github.com/wakamex/model-prices/commit/5b3662c6de4b552e58b68df9bbfa61828aeb82fa)).
