model-prices 0.0.5 can estimate models sold with no per-token price, prices Batch API requests, and comes with a website, [model-prices.com](https://model-prices.com/), that lists every model's price history and has a calculator. Price data keeps updating without a release through `model_prices.refresh()`, and the published data still uses schema v1, so earlier installs keep working. Batch prices and the other data fixes below reach them too; only `estimate=True` needs this release.

## Changes that affect callers

- `rates()`, `cost()`, and `model-prices rate --estimate` take `estimate=True` to price a model that is sold with no per-token price at the rates of a stated stand-in. The first is Muse Wonder Full, which Meta includes only in its Muse Code subscriptions and which is priced as `muse-wonder-1.0`. The returned `Rates.estimated_from` names the stand-in, so the figure can be labelled as an estimate; without `estimate=True` these models still return `None`. The stand-ins live in `data/estimates.toml` with their reasons and sources, and changing them changes `pricing_basis()` ([`cfad184`](https://github.com/wakamex/model-prices/commit/cfad1844b0c3d389e42c63522efce7a4ae9ca00a)).
- `mode="batch"` prices a request sent through a provider's Batch API: half price at Anthropic, OpenAI, and Google, and 20% off seven Grok models at xAI, from the date each discount began. Google keeps cache reads at the standard price for its Gemini 2.5, 3 Flash, and 3.1 Pro models. A model or time without a batch discount returns `None` ([`6ff6355`](https://github.com/wakamex/model-prices/commit/6ff6355ee180df48b434e323198006a8d8fa5d8c)).
- Google's Lyria music models, which are billed per song, are no longer priced at $0 per token; they now return `None` ([`2d7f332`](https://github.com/wakamex/model-prices/commit/2d7f3325583bacf8cc373f2550e62a26283159b0)).
- `muse` is a provider hint for Meta, like `claude` and `codex` for their labs ([`03efa0b`](https://github.com/wakamex/model-prices/commit/03efa0b254e3a97f78b68e9f257c78ce4dde59a5)).
- The snapshot records under `status` which models models.dev marks deprecated or no longer lists ([`7db0979`](https://github.com/wakamex/model-prices/commit/7db0979c279f930120c1b73d8465cf86601db635)).
