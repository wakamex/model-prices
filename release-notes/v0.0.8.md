model-prices 0.0.8 prices service tiers, such as flex and priority processing, and requests served in a region, such as Anthropic's US-only inference and OpenAI's regional processing endpoints. Calls that do not ask for a tier or a region cost what they did.

## Changes that affect callers

- Every service tier [models.dev](https://models.dev) prices is a mode named after the tier, the name the provider's API takes: `rates(model, mode="flex")` and `mode="priority"` price Google's, Amazon Bedrock's, xAI's, MiniMax's, and OpenAI's tiers, and `mode="ultrafast"` OpenAI's. OpenAI's existing `fast` mode gives the same prices as `priority`, and tier modes now price long prompts at the tier's long-context rates instead of its short-context ones ([`5864eaf`](https://github.com/wakamex/model-prices/commit/5864eaf28ff96d80ecb95521f2edac1567e7bf5e)).
- `rates()` and `cost()` take `region`, and `Rates.regions` lists the factor a model's token prices take in each region it prices apart: `region="us"` prices Anthropic's US-only inference on Claude 4.6 and later and xAI's US endpoint at 1.1 times, after any mode or batch discount, and sets `Rates.region`. A region the model does not list leaves its prices unchanged. `model-prices rate MODEL --region us` does the same from the command line ([`d65bcf0`](https://github.com/wakamex/model-prices/commit/d65bcf0597dd9bf78a237b979ad1b823db872430)).
- OpenAI's 10% uplift on its regional processing endpoints, `us`, `eu`, and `ae`, applies to the models OpenAI released on or after 2026-03-05, from 2026-10-31: `region="eu"` prices GPT-6.1 Sol at $2.20 input instead of $2.00. The rule, the regions that process each model, and each model's release are read daily from OpenAI's pricing page, data residency table, model pages, and API changelog, so no list is kept by hand, and the check fails when OpenAI's pages disagree about a model ([`fe00013`](https://github.com/wakamex/model-prices/commit/fe000139a638667cf5d559768ad51c6f0659b401)).

## Price data

- `model-prices check` compares OpenAI's Flex, Fast, and Ultrafast tables, Google's Flex and Priority sections, and OpenAI's regional factors with these prices; all of them that models.dev or OpenAI's pages price match ([`5864eaf`](https://github.com/wakamex/model-prices/commit/5864eaf28ff96d80ecb95521f2edac1567e7bf5e), [`fe00013`](https://github.com/wakamex/model-prices/commit/fe000139a638667cf5d559768ad51c6f0659b401)).
- The website at [model-prices.com](https://model-prices.com/) shows tier price histories and each model's regional factors, and its calculator offers a model's regions ([`d65bcf0`](https://github.com/wakamex/model-prices/commit/d65bcf0597dd9bf78a237b979ad1b823db872430)).
