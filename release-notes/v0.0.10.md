This release bundles the price data published on 2026-11-09, so an install that never calls `refresh()` gets the models and prices added since 0.0.9, and adds subscription plan prices for every lab model-prices tracks.

## Highlights

- Bundled data now includes models added since 0.0.9, such as Claude Fable 5.2 (`claude-fable-5-2`), Meta's Muse Ember 1.0 with its long-prompt tier, and OpenAI's image and speech models (`gpt-image-1.5`, `gpt-image-1-mini`, `chatgpt-image-latest`, `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-4o-mini-tts`), which OpenAI prices only by modality. ([`ac0c4e3`](https://github.com/wakamex/model-prices/commit/ac0c4e30ba904676353dd528cd5573521783661e), [`645f521`](https://github.com/wakamex/model-prices/commit/645f521e7ce3d452938c7806ce3511edc49d92a0))
- `plan(provider, plan_id)` covers 67 plan entries across 15 labs, including team seats, from each lab's own pricing page, with dated changes such as Anthropic's renaming of Max 20x to Ultra and Alibaba's Token Plan price cuts. ChatGPT's untiered `pro` is priced only before OpenAI added the $100 tier on 2026-04-09, since from then it names several prices. ([`ededa52`](https://github.com/wakamex/model-prices/commit/ededa5287c2fb1fd075fdcc74c164e4930b7cee7), [`3db800a`](https://github.com/wakamex/model-prices/commit/3db800a10f34ba00069b5e97348575f9af839d5a), [`54e5d70`](https://github.com/wakamex/model-prices/commit/54e5d70ef9855e5be02f4841a91a5273fe813f95))
- `model-prices check` compares plan prices with each lab's page daily, fails when a page drops a table it reads, compares xAI's batch discount list, and lists as unchecked any rule entry or page-read price no page stated that day. ([`3db800a`](https://github.com/wakamex/model-prices/commit/3db800a10f34ba00069b5e97348575f9af839d5a), [`7d11bdb`](https://github.com/wakamex/model-prices/commit/7d11bdb24b9b5b4554b88c81ee20ab3901229607), [`82d3bf7`](https://github.com/wakamex/model-prices/commit/82d3bf7fad0e03ed21e955d5ebc4efbc8ea3c7ee))
- Price checks read the new layouts of Google's, Tencent's, Devin's, Sakana's, StepFun's, Z.ai's, and Meta's pricing pages, restoring comparisons that had stopped without failing for StepFun's audio models and Z.ai's older text models.
