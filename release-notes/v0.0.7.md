model-prices 0.0.7 prices audio, image, and video tokens at their own prices, prices Alibaba's explicit cache hits, and applies price changes that providers announce ahead of time on their date. Callers that pass the same arguments as before get the same costs, except where a price was wrong: the price data, which earlier releases also fetch, now carries the scheduled changes and a corrected first price for many models.

## Changes that affect callers

- `cost()` and `Rates.breakdown()` take `modality_tokens`, a request's input, cached input, and output tokens by modality, such as `{"text": {"input": 800}, "audio": {"input": 2500, "cache_read": 1000}}`, in place of the plain counts, and `Rates.modalities` lists the prices a model states for each modality. On `gpt-realtime-1.5` audio input then costs $32 per million instead of the $4 text price, and on Gemini 3.1 Flash Image text and thinking output costs $3 instead of the $60 image price. Passing both kinds of count, an unknown modality, or a negative count raises `ValueError`. The README maps Gemini's, OpenAI Realtime's, Chat Completions', and the Images API's usage reports to it ([`2b41fde`](https://github.com/wakamex/model-prices/commit/2b41fde9ed80569ad6d2e82f760da8acd6d94a90)).
- `cost()` and `Rates.breakdown()` take `cache_read_explicit_tokens`, cache hits on prefixes the request marked for caching, which Alibaba bills at 10% of input against 20% for other hits, as `Rates.cache_read_explicit` gives, such as $0.04 against $0.08 per million for `qwen-plus` ([`ec91066`](https://github.com/wakamex/model-prices/commit/ec91066aabe7766482996bda4ed5ee47075f3e37)).
- Price changes a provider announces ahead, which [models.dev](https://models.dev) records with their date, take effect at 00:00 UTC on that date with `Rates.valid_from_basis` set to `scheduled`: Gemini 4 Argon doubles to $4 input and $20 output on 2026-12-01, and six other Gemini models double on 2027-01-01. The price history can therefore hold prices that start in the future, which `rates()` applies from their date ([`4b1815d`](https://github.com/wakamex/model-prices/commit/4b1815d0c6c12715cd2817f6c8665de7939e14ce)).
- A correction to a model's first recorded price now also prices usage before that record, as the first price itself does, so earlier usage of 104 corrected models no longer gets models.dev's uncorrected first price ([`be0461a`](https://github.com/wakamex/model-prices/commit/be0461a8440eae085ab9e3358d2a19ccc5370a36)).

## Price data

- `model-prices check` compares each modality price on Google's and OpenAI's pricing pages, and corrections, each dated by an archived copy of the page, give the text output of Google's image and video models and the cached audio and image prices models.dev omits for `gpt-realtime-2.1` and `gpt-image-2` ([`2b41fde`](https://github.com/wakamex/model-prices/commit/2b41fde9ed80569ad6d2e82f760da8acd6d94a90)).
- The check compares models.dev's peak-hour multipliers and cache write prices by lifetime with model-prices' own rules, which found Alibaba's half-price off-peak hours on three more DeepSeek models it resells ([`ec91066`](https://github.com/wakamex/model-prices/commit/ec91066aabe7766482996bda4ed5ee47075f3e37)).
- Mistral Large 4 costs $0.70 input and $2.10 output from 2026-10-29 ([`c33db94`](https://github.com/wakamex/model-prices/commit/c33db94d4eeddd9d536f22992f72455cecddb334)), and Gemini's native-audio preview no longer gets batch prices, since it has no batch API ([`56bef95`](https://github.com/wakamex/model-prices/commit/56bef95ced410e69c7b14b6f54a3030f318f01b4)).
- The website at [model-prices.com](https://model-prices.com/) shows prices by modality and scheduled changes, and its calculator takes tokens by modality ([`2b41fde`](https://github.com/wakamex/model-prices/commit/2b41fde9ed80569ad6d2e82f760da8acd6d94a90)).
